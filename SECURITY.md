# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in DataEngineCore, please report it
privately through GitHub Security Advisories:

**https://github.com/Mendl-Labs/DataEngineCore/security/advisories/new**

Please do **not**:

- Open a public GitHub issue or discussion for a security report
- Email a personal address with vulnerability details

Reporting privately gives us a chance to investigate and ship a fix before
the details are public.

## What to Include

To help us triage quickly, please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce it (a minimal repro is ideal)
- The affected version/commit, if known

## Response

We will acknowledge new reports and keep you updated as we investigate and
address the issue.
